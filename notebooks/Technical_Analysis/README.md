# 📓 Notebooks / Technical_Analysis

This folder contains all Jupyter notebooks used for systematic technical stock analysis.

The notebooks are modular, well-documented, and designed to be used independently or as part of a complete market analysis workflow.

Notebooks are numbered to reflect the recommended reading and execution order.

---

## 📂 Notebook Overview

### `01_EMA_and_MACD.ipynb`
Analyzes a selected stock (TICKER) using EMA20, EMA50, EMA200, and MACD indicators over a 3-year period to identify trends and momentum shifts.

---

### `02_Moving_Averages_and_Price_Views.ipynb`
Calculates SMA50 and SMA200 for a stock and visualizes price movements over multiple timeframes, including the last year, to highlight trends and potential reversals.

---

### `03_Candlestick_Charts_Short_Term.ipynb`
Visualizes short-term price action with candlestick charts for the last month and last 5 trading days, providing insights into intraday trends and volatility.
